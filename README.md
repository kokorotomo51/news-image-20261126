# news-image-20261126

One image summing up world news first reported on Thursday 26 November 2026:
the lead story is Kim ordering tactical nuclear weapons spread across
multiple domains and nuclear-material output expanded, as reported
Thursday by KCNA; alongside it, Russia striking two foreign grain ships
near Odesa, fresh claims about Bardella in the French press, a
researcher naming China's MiniMax as the AI firm whose user data was
accessed by unidentified parties, and the AI sell-off dragging markets
down. Stories first reported earlier are kept in a footer labelled as
such, never in the main content.

Bounty: https://make.fun/bounty/news-image-20261126

`main.py` (pure Python standard library, no network, no clock, no
randomness) draws the 1024×1024 PNG deterministically: two runs write
identical bytes. Run it with `MAKEFUN_OUTPUT_DIR` set to the output
directory, or let it default to `/output`.
